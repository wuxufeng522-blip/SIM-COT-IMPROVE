# SIM-CoT 强错误—显式自纠—正确答案完整析因实验设计

**日期：** 2026-08-26

**状态：** 用户已批准设计，等待书面规格复核

**硬件：** RTX 4060 8GB

**实验性质：** Codex 构造的受控强反事实压力实验，不是自然教师噪声发生率实验

## 1. 研究问题

本实验回答两个依次成立的问题：

1. 当一条 CoT 的中间步骤包含语义连贯但大幅偏离正确推理的错误，而该 CoT 随后显式纠错并由自身得到正确最终答案时，等权步骤监督是否仍会损害 SIM-CoT 的干净测试正确率？
2. 在已知错误步骤位置的 oracle 条件下，将错误步骤相对权重降至 0.1，能否缓解上述伤害？

本实验不估计自然教师产生这类轨迹的频率，也不把构造数据称为自然教师噪声。它首先验证“错误过程—正确答案”条件下步骤加权是否存在因果必要性。只有 oracle 降权显示稳定收益后，才有理由继续训练可靠性头。

## 2. 与此前实验的关键区别

此前全链强冲突实验保持了正确答案标签，但错误 CoT 自身通常得到错误答案。因此步骤损失与答案损失形成了人工的终点冲突。

本实验要求所有版本都满足：

- CoT 自身的最后一步得到官方标准答案；
- 含噪版本保留规定数量的强错误步骤；
- 后续步骤明确承认错误并恢复正确推理；
- 正确答案不是孤立地粘贴到错误链末尾。

因此，本实验固定最终答案正确，只改变中间步骤的正确性、错误类型、错误剂量和错误步骤权重。

## 3. 数据来源与构造原则

### 3.1 基础题目

- 从官方 MATH 训练分区选择 512 道题。
- 官方数据只必须提供题目和标准答案，不要求预先包含本实验所需的错误步骤类型。
- 题目与最终测试集按规范化题目哈希严格去重。
- 若现有轨迹不是合格的五步正确 CoT，则由当前 Codex 任务构造五步 Clean 轨迹。

### 3.2 五联组

每道题构造五条严格配对的五步轨迹，共 `512 × 5 = 2560` 条：

| 版本 | 第 2 步 | 第 3 步 | 第 4 步 | 第 5 步 |
|---|---|---|---|---|
| Clean | 正确 | 正确 | 正确 | 推导出正确答案 |
| 解法错误 Noise-1 | 强错误 | 显式纠错 | 正确恢复 | 推导出正确答案 |
| 解法错误 Noise-2 | 强错误 | 因果延续错误 | 显式纠错并恢复 | 推导出正确答案 |
| 题意误读 Noise-1 | 强错误 | 显式纠错 | 正确恢复 | 推导出正确答案 |
| 题意误读 Noise-2 | 强错误 | 因果延续错误 | 显式纠错并恢复 | 推导出正确答案 |

所有五个版本使用同一道题和同一标准答案，步骤数量固定为五。每个含噪版本的辅助监督 token 总数必须处于对应 Clean 版本的 0.9—1.1 倍范围内；不满足时重新构造，避免用文本长度解释训练差异。

### 3.3 两个强冲突族

**错误解法分支（solution-branch error）**

- 使用错误公式、错误约束、错误建模或根本错误的推导方向；
- 文本必须保持语义连贯，像一个能力不足的教师正在认真解题；
- 错误必须改变核心变量、中间结论或所需运算，不能只是孤立的排版错误。

**题意误读（problem-misread error）**

- 错误解释关键条件、对象、关系或求解目标；
- 后续错误步骤必须继续求解被误读的问题；
- 不允许使用随机乱码或与题目完全无关的文本。

强错误步骤与其对应 Clean 步骤的归一化编辑距离必须至少为 0.4，并通过语义规则确认其改变了解题分支，而非只做表面措辞替换。

### 3.4 错误剂量和标签

- Noise-1 恰好有一个 `-1` 步骤：第 2 步。
- Noise-2 恰好有两个连续且因果相承的 `-1` 步骤：第 2、3 步。
- 显式纠错步骤标记为 `+1`。它必须否定错误分支、指出错误性质，并重新建立正确推导。
- 正确恢复步骤和最终正确答案步骤均标记为 `+1`。
- 纠错步骤可以概括前一错误，但不得继续把错误结论当作有效前提。

### 3.5 不再设置“自然噪声数量门”

主实验不依赖 PRM800K 中是否存在现成的“错误步骤—正确答案”轨迹：

- 缺少 Clean 五步轨迹时，由 Codex 构造；
- 缺少任一强冲突类型时，由 Codex 构造；
- 单条构造失败时重新构造，仍不合格则更换基础题目；
- 不降低错误强度、错误数量、五步结构或最终答案正确要求；
- 直至形成 512 套完整合格五联组后才冻结数据并进入训练。

这仍保留质量门，但不存在因自然 Noise-1/Noise-2 样本不足而终止主实验的数据门。

### 3.6 PRM800K 补充集

将此前发现的 46 条自然 Noise-1、最终答案错误的 PRM800K 轨迹接入受控的显式纠错段，使修改后的轨迹自身得到正确答案。该集合用于定性检查主实验构造是否过于特殊，不混入 512 道主训练题，不参与主要显著性结论。修改后的补充轨迹同样只能称为半合成轨迹。

## 4. 数据验证与冻结

每条轨迹必须通过以下检查：

1. 恰好五个监督步骤；
2. Noise-1/Noise-2 分别恰好含一个/两个错误步骤；
3. Noise-2 的两个错误步骤在语义上因果相承；
4. 显式纠错步骤明确撤销错误分支；
5. 第五步从恢复后的正确推导得到答案；
6. 官方 grader 判定最终答案正确；
7. 强冲突改变核心公式、变量、条件解释或求解目标；
8. 训练题与官方 MATH 测试题不存在规范化题目哈希重复；
9. 所有原始生成、修改、标签、拒绝原因和重试记录均保留。

训练前固定抽取 20 道题，展示其完整五联组供人工审计。审计不通过的样本只能重新构造或替换，不能放宽标准。

合格数据写入不可覆盖的原始记录和冻结 manifest，并记录文件 SHA-256。所有训练臂共享完全相同的问题清单、版本映射和样本顺序。

## 5. 完整析因训练设计

### 5.1 九个训练臂

| 训练臂 | 污染族 | 错误步骤数 | 错误步骤相对权重 |
|---|---|---:|---:|
| Clean | 无 | 0 | 不适用 |
| 解法-1-等权 | 错误解法 | 1 | 1.0 |
| 解法-1-加权 | 错误解法 | 1 | 0.1 |
| 解法-2-等权 | 错误解法 | 2 | 1.0 |
| 解法-2-加权 | 错误解法 | 2 | 0.1 |
| 题意-1-等权 | 题意误读 | 1 | 1.0 |
| 题意-1-加权 | 题意误读 | 1 | 0.1 |
| 题意-2-等权 | 题意误读 | 2 | 1.0 |
| 题意-2-加权 | 题意误读 | 2 | 0.1 |

三个固定种子为 `20260809`、`20260810`、`20260811`，总计 27 次独立训练。

### 5.2 加权损失

总损失保持为：

\[
L = L_{\text{answer}} + \lambda L_{\text{steps}}, \qquad \lambda=1.
\]

五步加权损失为：

\[
L_{\text{steps}}
=
\frac{5\sum_{i=1}^{5} w_i L_i}{\sum_{i=1}^{5} w_i}.
\]

- 等权臂所有步骤的原始权重均为 1。
- 加权臂中 `-1` 错误步骤的原始权重为 0.1，其余步骤为 1。
- 0.1 表示错误步骤相对于正确步骤的权重比例。
- 分母归一化保持每条轨迹的平均步骤权重为 1，避免把“选择性降权”与“整体辅助损失减弱”混为一谈。
- 答案损失在九组中完全相同，不参与步骤权重归一化。
- 显式纠错步骤是正确监督，原始权重为 1。

这里使用真实构造标签提供的 oracle 权重，尚不训练可靠性头。

### 5.3 固定训练条件

所有训练臂必须：

- 从同一个官方 SIM-CoT 检查点初始化；
- 使用同一批 512 道题和相同题目顺序；
- 使用相同更新数、优化器、学习率和梯度累积；
- 使用 `bf16`、最大序列长度 1024、梯度累积 8、学习率 `1e-4`、权重衰减 `0.01`、梯度裁剪 `1.0`；
- 保持 `latent_stage=5`、`c_thought=2`、`lambda_aux=1.0`；
- 每臂执行 64 个正式更新；
- 禁止从其他训练臂的检查点恢复。

## 6. 训练前工程验证

正式训练前完成：

1. 五联组结构和答案 grader 单元测试；
2. 错误数、错误位置、权重向量及归一化公式测试；
3. Clean 与四个等权臂的初始答案损失可比性检查；
4. 验证加权臂只有指定错误步骤的相对梯度贡献被降至 0.1；
5. 九个训练臂各运行两个更新的显存与数值 sanity test；
6. 检查 loss、梯度和参数均为有限值；
7. 峰值保留显存不得超过 7.4GB。

工程检查失败时允许修复实现错误并从同一训练臂安全续跑，但不得修改冻结数据、种子、训练臂、权重、更新数或判定标准。

## 7. 评估设计

### 7.1 测试集

- 所有模型仅在未加噪的官方 MATH 测试题上评估；
- 测试时不提供步骤标签、标准答案或人工噪声；
- 主评估使用固定的 500 道官方测试题；
- 所有训练臂生成逐题预测，使用同一官方 grader；
- 用户已要求本轮不因低基线正确率而停止，但报告必须说明地板效应会降低统计功效。

### 7.2 指标

主要指标：

- 官方 grader 最终答案正确率；
- 标准化答案 EM；
- 三种子均值和逐种子结果；
- 基于相同测试题的 95% 分层配对 bootstrap 置信区间，固定 10,000 次重采样。每次先对三个种子有放回抽样，再在选中的每个种子内对 500 个共同题目 ID 有放回抽样；同一抽样索引同时用于被比较的两个训练臂。

核心效应定义为：

\[
\text{伤害量}_{f,d}
=
Acc_{\text{Clean}}-Acc_{f,d,\text{equal}},
\]

\[
\text{加权恢复量}_{f,d}
=
Acc_{f,d,\text{weighted}}-Acc_{f,d,\text{equal}},
\]

\[
\text{恢复比例}_{f,d}
=
\frac{\text{加权恢复量}_{f,d}}{\text{伤害量}_{f,d}},
\]

其中 `f` 表示错误解法或题意误读，`d` 表示 Noise-1 或 Noise-2。只有伤害量大于 0 时才解释恢复比例。

剂量效应为同一污染族中 Noise-2 伤害量减去 Noise-1 伤害量。污染族差异为相同剂量下题意误读与错误解法的伤害量之差。

## 8. 结果判定

### 8.1 错误步骤伤害

确认存在伤害需要同时满足：

- 三种子平均伤害量大于 0；
- 至少两个种子的方向一致；
- 95% 配对 bootstrap 置信区间不跨 0。

平均下降达到 2 个百分点时，额外标记为具有实际意义的伤害。

### 8.2 Oracle 降权有效性

确认加权有效需要同时满足：

- 三种子平均加权恢复量大于 0；
- 至少两个种子的方向一致；
- 95% 配对 bootstrap 置信区间不跨 0。

恢复至少 1.5 个百分点且挽回对应伤害的 50% 以上时，额外标记为具有实际意义的恢复。

### 8.3 允许的四种结论

1. **有伤害且可恢复：** 最支持继续研究可靠性头和步骤加权。
2. **有伤害但不可恢复：** 支持噪声伤害，但当前 0.1 权重或加权位置不足。
3. **无伤害但加权提升：** 不能称为噪声修复，可能来自正则化或损失重分配。
4. **无伤害且无恢复：** 在当前模型、数据量和强冲突定义下，加权监督缺乏必要性。

两类污染族分别分析。只有两族结果方向一致时，才能说明结论不依赖单一人工错误模板。无论结果是否显著，九个训练臂和三个种子的结果都必须完整报告。

## 9. 执行与安全续跑

- 27 个训练作业在单张 RTX 4060 上顺序执行。
- 每个“种子 × 训练臂”拥有独立输出目录、检查点和状态记录。
- 状态机分别记录数据、sanity、训练、评估和分析阶段。
- 工程故障只允许从当前配置自身的状态恢复；不得覆盖原始生成记录或跨配置恢复训练。
- 根据此前 15 次同规模训练约 2 小时 19 分钟的实测，27 次训练与评估预计约 4—6 小时；加上数据构造和审计，目标是在一夜内推进完整流程，但不得为赶时间跳过数据验证。

建议工作目录：

- `work/reliable_simcot/self_corrected_strong_conflict/`
- `outputs/reliable_simcot/self_corrected_strong_conflict/`

## 11. 可解释边界

本实验允许声称：

> 在 Codex 构造的、包含强错误但能够显式自纠并最终答对的 CoT 中，等权步骤监督是否伤害 SIM-CoT，以及 oracle 步骤降权是否缓解该伤害。

本实验不允许直接声称：

- 自然教师经常生成这类轨迹；
- 当前构造错误代表所有自然教师噪声；
- oracle 标签可以在测试时直接获得；
- 未经额外实验，可靠性头一定能复制 oracle 加权收益。
