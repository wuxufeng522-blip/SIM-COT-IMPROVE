# PRM800K 自然步骤噪声伤害实验：数据门报告

**日期：** 2026-08-26  
**状态：** `INSUFFICIENT_STRICT_TRIPLETS`  
**训练状态：** 未启动（按批准规格在数据门停止）

## 结论

官方 PRM800K 训练分区无法形成本实验要求的 Clean / Noise-1 / Noise-2 严格三联组。所需数量为 512，实际数量为 0。因此不能在不修改预注册数据定义的情况下启动四臂三种子训练。

这不是“自然错误步骤没有伤害”的实验结果，也不是模型性能结果；它只说明 PRM800K 的原始采集结构不支持当前严格对照。

开发集 Clean 数量足够，但训练所需的含错轨迹不存在，不能只训练 Clean 后把它称为自然噪声对照。

## 为什么会得到 0 个三联组

PRM800K Phase 2 在发现首个错误后通常停止标注；在恰好五步的记录里，含 `-1` 的路径没有继续形成“一个或两个错误、随后仍由原模型回到正确最终答案”的完整 chosen 轨迹。本次发现的 46 条五步 Noise-1 原始路径，其预生成最终答案全部被官方 grader 判错。Phase 1 中一旦模型候选均错误，常由人工 completion 接管，而本实验按规格排除了人工替换。因此：

- 严格 Noise-1 最终答案正确样本为 0；
- 严格 Noise-2 在结构层面即为 0；
- 无法进行同题、同 generation、同最终正确答案的剂量对照。

## 可解释边界

本轮允许的结论是：

> 在“原始 chosen completion、恰好五步、无人工替换、标签仅 ±1、模型最终答案正确、同题同 generation”的约束下，官方 PRM800K 没有足够数据支持自然步骤噪声伤害训练实验。

本轮不允许声称：

- 自然教师错误对 SIM-CoT 无害；
- 一处或两处错误不会降低准确率；
- PRM800K 中不存在自然错误；
- 降权监督无意义。
