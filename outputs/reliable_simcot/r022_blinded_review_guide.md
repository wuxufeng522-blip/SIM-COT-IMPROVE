# R022 自然教师步骤盲评说明

## 目的

独立判断官方训练步骤的两种属性：

- **Validity（有效/正确）**：该步骤的事实、算术或推理是否与题目及其前序步骤相容。
- **Utility（有用）**：仅当 `y_valid=1` 时，该步骤是否对得到最终答案提供了非冗余推进。

本轮用于估计自然低可靠性步骤的流行率，不用于挑选“看起来可疑”的样本。请按 CSV 给定顺序完成，不查看 `r021_auto_triage` 或 `overlap_ids.txt`。

## 填写规则

1. `y_valid` 只能填 `1` 或 `0`。
   - 填 `1`：计算/事实/逻辑正确，且所用前提能从题目或前序步骤得到。
   - 填 `0`：算术错误、引用错误数量、逻辑不成立、与题目矛盾，或步骤为空。
   - 合理的近似、四舍五入、向上/向下取整，应结合题目语义判断，不因小数形式不同自动判错。
2. `y_utility` 只在 `y_valid=1` 时填写。
   - 填 `1`：引入后续需要的中间量、必要关系或直接支持最终答案。
   - 填 `0`：虽然正确，但与求解无关、重复已有信息，或没有提供实际推进。
   - 若 `y_valid=0`，`y_utility` 必须留空；不要填 `0`。
3. `confidence` 填 `high`、`medium` 或 `low`。低置信度必须在 `review_notes` 简述分歧点。
4. 不要修改 `review_order`、`assignment_role`、`audit_row_id` 或任何题目内容列。

## 文件分工

- 评审 A：`r022_blinded_review_v2/reviewer_a.csv`
- 评审 B：`r022_blinded_review_v2/reviewer_b.csv`

两位评审应独立完成。约 10% 的行被重复分配，用于计算一致性；CSV 不显示哪些是重叠行。完成前不要相互讨论具体样本。

请不要直接覆盖模板；分别另存为 `reviewer_a_labeled.csv` 和 `reviewer_b_labeled.csv`，以便程序核对所有不可编辑字段。

## 边界示例

- `<<1/3=0.33>>`：若题目允许近似，通常可视为有效。
- 正确地重复同一计算：Validity 可为 1，但 Utility 可能为 0。
- 算术本身正确但使用了题目中不存在的数值：Validity 为 0。
- 最后一步给出连续值、答案要求箱数/人数等离散量：需判断是否缺少必要取整推理；不要仅按字符串是否相等判断。
