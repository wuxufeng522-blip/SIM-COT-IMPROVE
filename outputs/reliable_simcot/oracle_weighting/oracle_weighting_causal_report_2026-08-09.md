# 正确判别后降低含噪步骤权重：因果验证报告

日期：2026-08-09

## 结论先行

本轮得到的是**积极但尚未完全确证**的结果。

- 用户提出的原始方案（污染步权重 0.1、干净步权重 1.0）比含噪等权组多答对 17 题，EM 提高 1.289 个百分点；但配对 95% 置信区间跨 0，McNemar `p=0.159`，单独看还不能排除随机波动。
- 保持平均步骤权重为 1 的归一化 0.1 方案比含噪等权组多答对 26 题，EM 提高 1.971 个百分点；配对 95% 置信区间为 `+0.227` 至 `+3.715` 个百分点，McNemar `p=0.0329`。这是本轮最强的正向证据，说明改善不只是“整体少算了一些辅助损失”，正确地把梯度从污染步转移到干净步更可能有用。
- 但是，含噪等权组相对干净续训组只下降 0.758 个百分点，低于事先冻结的 1 个百分点损伤阈值，且该差异不显著。因此严格的预注册式判定是：**本轮机制测试不确定（污染造成的可观测损伤不足）**，不能写成已经完全证明。
- 四个续训组都低于未经续训的官方 checkpoint 28 基线 44.43%。所以本轮只证明同预算受控续训中的相对趋势，不证明该训练配方已经提高官方 SIM-CoT 的绝对性能。

## 实验设置

- 起点：同一个官方 SIM-CoT checkpoint 28。
- 训练：每组 256 次优化更新，梯度累积 8，合计每组 2,048 个微批次；四组样本顺序、初始化、优化器、学习率和逐微批 dropout 种子完全一致。
- 数据：每题前五个可程序检查的算术步骤中恰好污染一个，污染率 20%。
- 污染：五个污染族与五个步骤位置组成 25 个联合单元，每格 81–82 条。
- Oracle 判别：污染位置来自数据生成器的真实记录，不由大模型或可靠性头预测。
- 答案损失：四组始终等权且输入完全相同；仅辅助步骤损失不同。
- 主评估：官方 1,319 题测试集，以数据集答案字段为唯一真值。
- 单次训练种子：20260809。

四个实验组：

| 组别 | 训练步骤 | 步骤权重 |
|---|---|---|
| clean | 五步均为干净步骤 | 全部 1.0 |
| noisy_equal | 一步污染、四步干净 | 全部 1.0 |
| oracle_raw_0.1 | 与 noisy_equal 完全相同的污染 | 污染 0.1，干净 1.0，平均 0.82 |
| oracle_normalized_0.1 | 与 noisy_equal 完全相同的污染 | 保持污染/干净比为 0.1，再归一化到平均 1.0 |

## 关键发现

1. **观察：正确降权的两个点估计都高于含噪等权组。** 原始 0.1 提高 1.289 pp，归一化 0.1 提高 1.971 pp。
   **解释：** 已知污染步骤产生的梯度很可能确实会干扰模型，把梯度预算重新分给干净步骤有帮助。
   **含义：** “先判断、再按步骤加权”值得继续，而不是直接放弃。
   **下一步：** 用更强、能稳定造成至少 1 pp 损伤的污染强度复验。

2. **观察：归一化 0.1 相对含噪等权组达到配对显著，而原始 0.1 没有。**
   **解释：** 原始 0.1 同时减少了污染梯度和总辅助梯度；归一化版本保持总权重，强化了干净步骤，信号更清楚。
   **含义：** 后续主方法应优先采用“题内归一化的相对权重”，而不是未经归一化的绝对 0.1。
   **下一步：** 保留两者作为消融，但把 normalized 0.1 作为机制主组。

3. **观察：等权污染相对干净续训只损失 10 题，差异不显著。**
   **解释：** 20% 的辅助步骤污染可能太弱；答案损失保持干净、其余四步也干净，模型可以抵消一部分污染。
   **含义：** 当前数据不足以严格声称“0.1 恢复了由噪声造成的损伤”。归一化组的提高也可能包含正则化或重新分配干净梯度的收益。
   **下一步：** 把每题污染从 1/5 提高到 2/5，并首先确认 noisy_equal 对 clean 的损伤闸门。

4. **观察：所有续训组都未超过原始官方 checkpoint 的 44.43%。**
   **解释：** 从训练后期 checkpoint 继续用固定 1e-4 学习率训练 256 次会产生分布漂移。
   **含义：** 本轮能回答加权机制的相对问题，不能作为最终方法的绝对性能结果。
   **下一步：** 正式实验应从可复现的官方训练阶段接入，或降低续训学习率并加入原始 checkpoint 不训练对照。

## 建议的下一轮判定实验

优先做一个仍可在 RTX 4060 8 GB 上一晚完成的增强版：

1. 固定同一批 2,048 条样本，把污染提高到每题 2/5 步（40%）。
2. 复用本轮 clean 作为同种子对照，只重训 noisy_equal、raw 0.1、normalized 0.1，预计约 2 小时训练加 15 分钟评估。
3. 先检查 noisy_equal 相对 clean 是否损伤至少 1 pp；未达到则停止解释恢复率。
4. 若损伤闸门通过，要求 normalized 0.1 至少恢复一半损伤，并报告配对区间。
5. 初筛通过后再补 3 个训练种子，报告均值、标准差和种子级一致性；单种子的 `p=0.0329` 不能代替训练可重复性。

## 可用于论文/记录的谨慎表述

在单种子、20% 受控辅助步骤污染下，oracle 归一化步骤加权相对含噪等权训练将 GSM8K-Aug EM 提高 1.97 个百分点（配对 95% CI 0.23–3.71 pp），但含噪等权组相对干净续训的损伤未达到预设阈值；因此该结果支持继续研究正确判别后的步骤降权机制，但尚不足以证明其在自然教师噪声或跨训练种子条件下稳定有效。
