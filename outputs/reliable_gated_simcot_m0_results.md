# M0 实验结果：官方 SIM-CoT 复现与 RTX 4060 单卡预检

日期：2026-08-05

硬件：NVIDIA GeForce RTX 4060 Laptop GPU，8188 MiB
勘误并完成修正版复跑后的结论：**R001–R005 全部 PASS。官方 checkpoint 数值复现、修正步骤解析后的 20-step 训练、checkpoint 重载与续训均已在 RTX 4060 8GB 上通过。R010–R012 仍因官方未发布 checkpoint-24 而阻塞，不再受单卡预检阻塞。**

## 单卡训练与恢复预检

- 旧 R004：BF16、batch 1、梯度累积 8、20 次更新，峰值 reserved 显存 5.52 GB；只能证明该实现的显存路径曾运行，不能再证明训练数据语义与官方完全一致。
- 旧 R005：checkpoint 保存/重载与继续更新在旧解析下成功，同样只保留为工程证据。
- 发现原因：训练文本用 `####` 分隔答案；旧适配器按最后一个 `##` 切分，给每条轨迹添加了伪 `##` 步骤。官方 `preprocessing/gsm_icot.py` 使用第一个与最后一个字段，现已严格对齐。
- R004-v2 的“无 traceback 退出”经审计是外层命令超时，不是 CUDA、模型或数据崩溃；失败产物仍原样保留。
- 修正版 R004-v3：完成 20/20 次有限更新、梯度累积 8（160 个微批次）；前 5 次更新平均 loss `1.025684`，后 5 次 `0.000213449`，最终固定探针 loss `3.8306e-6`。峰值 reserved 显存 `5.5234 GB`，低于 `7.4 GB` 上限；checkpoint 重载探针差值为 `0`。判定 PASS。
- 修正版 R005-v3：从 R004-v3 checkpoint 重载后继续一次完整更新，loss 从 `3.8306e-6` 降至 `4.3710e-7`；第二次重载差值为 `0`，峰值 reserved 显存 `5.1406 GB`。判定 PASS。
- 结论：修正格式后的完整 `20-step + reload + resume` 单卡门槛已经通过。

## 必须保留的审计结论

1. 早期规格把官方表中的 `12.2` 误读成 GSM-Hard 正确率；它实际是平均生成 token 数。正确 OOD 目标是 9.3% / 90.8% / 40.7%，规格已勘误。
2. 作者引用的私有格式化 OOD JSON 未发布。MultiArith 合并公开的 180 test 与 420 train 才对应论文 600 题主表；只跑 test 得到的 92.78% 不可直接和 90.8% 比。
3. 发布版 `Coconut/run.py` 导入但没有调用辅助步骤监督数据函数。R004/R005 按论文意图启用该路径；正式实验必须把它记为官方实现差异。
4. 官方入口依赖 NCCL/DDP/FSDP，Windows 单卡采用兼容 adapter；官方模型类、tokenizer、latent 构造、checkpoint 和答案规则均保留，并由四任务数值反向核验。
5. R004-v3 原始指标：`outputs/reliable_simcot/r004_v3/metrics.json`；R005-v3 原始指标：`outputs/reliable_simcot/r005_v3/metrics.json`。旧 v2 失败记录保留，未被覆盖。

M0 当前证明官方 checkpoint 的四任务评测复现可信，且训练/恢复路径在 RTX 4060 8GB 上可行；它仍未证明可靠性加权方法有效。R010/R011 仅因缺少可验证的官方 checkpoint-24 而停止，停止规则允许继续做不涉及下游收益主张的可靠性检测可行性审计。
